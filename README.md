# Abyss-Launcher

## Banco de dados

O esquema completo e atualizado fica em `database.sql`. Use esse único arquivo ao criar o banco `projetofinal` em uma instalação nova.

A conexão local usa `localhost` e `root`/`root` como padrão. Em outros ambientes, configure `ABYSS_DB_HOST`, `ABYSS_DB_NAME`, `ABYSS_DB_USER` e `ABYSS_DB_PASSWORD` no servidor PHP.
